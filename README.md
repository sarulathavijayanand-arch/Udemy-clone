# Udemy Clone

A responsive Udemy-inspired online learning website created using **HTML and CSS**.

### Features

* Responsive navigation bar
* Search bar
* Course categories
* Flash sale banner
* Recommended courses
* Popular courses section
* Recommended topics
* Footer section
* Responsive layout using CSS Flexbox and media queries

### Technologies Used

* HTML5
* CSS3
* Flexbox
* Responsive Design

### Purpose

This project was created as a front-end practice/assessment project to understand website structure, styling, Flexbox, and responsive web design.
